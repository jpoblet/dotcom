# Content updates

Working files for the quarterly content update (see
`.claude/skills/content-update/SKILL.md`). The site and the chat never read
this folder: the content loader only reads `about/`, `projects/` and the
YAML files.

- `todo.md`: open content items, carried from one update to the next.
- `log.md`: one entry per update, newest first. The date of the latest
  entry is where the next update's signals start.
